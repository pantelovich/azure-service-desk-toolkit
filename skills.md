# Reusable Project Patterns

## Safe support automation

- Default to read-only collection.
- Redact personal information from fixtures and screenshots.
- Separate collection, diagnosis and report formatting so each can be tested.
- Treat authentication and permission failures as support findings, not silent failures.

## Portfolio evidence

- Show one realistic incident from symptom to escalation.
- Include commands, expected output and cleanup.
- Prefer a short troubleshooting record over decorative badges.
- State what was tested locally and what still needs a live tenant.
