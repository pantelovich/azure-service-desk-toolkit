# Context

## Goal

Create public evidence of practical Azure and service-desk ability that complements Pantelis's AWS-heavy GitHub portfolio.

## Target roles

- First-line IT support
- Service desk analyst
- Junior cloud support engineer
- Microsoft 365 or Azure support technician

## Evidence to demonstrate

- Microsoft Entra ID and Microsoft Graph
- PowerShell troubleshooting and automation
- Windows and Microsoft 365 support reasoning
- DNS, connectivity and account-state checks
- Clear case notes, escalation boundaries and audit-friendly output
- Bicep, Azure CLI and GitHub Actions

## Constraints

- The toolkit must run without a live tenant through sanitised demo data.
- Live mode must request only documented Graph permissions.
- No claim is added to a CV until its behaviour is tested.
